# Landing Page - Trabajo Colaborativo

## Información del proyecto

**Nombre del repositorio:** `landing-page-trabajo`

Este proyecto consiste en desarrollar una **Landing Page sencilla** utilizando HTML, CSS y JavaScript, simulando un entorno de desarrollo colaborativo mediante Git y GitHub.

Cada integrante del equipo trabaja de forma independiente en una rama asignada y posteriormente todos los cambios son integrados en la rama principal `main`.
